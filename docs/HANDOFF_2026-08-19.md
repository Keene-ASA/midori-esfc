## 1-bis. 🟢 フロンティア転換点が解析的に確定した（§4 の🟡未確認事項）

**0.25 でも 0.30 でもなく、0.2560**。しかも格子で探す必要がない**折れ点**だった。

```
fr* = 1 - CAP * sA_other / A50 = 1 - 0.75*0.248/0.25 = 0.2560
      a_rice = 0.124272   dCAB -2.934   dGHG +64.327 (+0.643 Mt/yr)
```

果樹の転換余地（CAP×sA_fruit）が尽き、米の限界的な代替相手が
**果樹（cost 0.4830）から その他（cost 0.1275）に切り替わる点**。米の cost は 0.1634 なので、
ここを境に「米を増やす」ことが CAB を改善から悪化に転じる。上り勾配 +9.355/unit、
下り勾配 −1.135/unit の非対称。

🟢 **この点は Part B の「CAB-optimal (cheapest first)」配分と厳密に同一**（a_rice 0.124、
dCAB −2.934、dGHG +64.327）。つまり**フロンティアの転換点と費用最小配分は同じ点である**、
という独立に導いた2つの結果の一致であり、実装の相互検証にもなっている。

🔴 本文は「rice share 0.25 を超えると」ではなく **「0.256 を超えると両方悪化」**。

## 2. 🟢 §5.6 に足せる一行論証（今回の副産物）

2050年の**排出項だけ**の合計は **+139.7799**。これは**平衡値と厳密に一致する**。

> 2050年に `a` と `pi` がランプ終端で目標値に固定されるため、排出フローはその時点で
> 既に恒久水準に達している。年次収支を負にしているのは**過渡的なストック蓄積のみ**である。

つまり「2050年の −1.390 Mt/年」と「平衡の +1.398 Mt/年」の差は、
**政策の効果が変わったからではなく、ストックが満たされ終わるから**。
ストックとフローを分けて記帳しなければ、この2つの数字は同じ政策の同じ年の記述として
矛盾して見える。**これが SFC 会計でしか出せない、という主張そのもの。**

台帳 `G 結果 / S2_dGHGnet_2050` に記録済み。

### 🔴 残る不一致は必ず開示する（深度）
